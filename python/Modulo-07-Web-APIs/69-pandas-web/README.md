# Nivel 69: La Aspiradora Mágica de Tablas (Pandas Web) 🌪️

Hasta ahora, si querías extraer información de una página web, usabas BeautifulSoup. Buscabas cada pedacito de texto usando pinzas: primero buscabas la fila, luego la columna, luego el texto... ¡Un trabajo agotador!

¿Qué pasaría si la página web tiene una tabla gigante con 200 países y sus poblaciones? Escribir bucles para extraer eso celda por celda es lento y propenso a errores.

Aquí es donde entra al rescate **Pandas**, la herramienta rey del análisis de datos en Python. Pandas tiene un "superpoder" oculto: una aspiradora mágica capaz de escanear una página web, encontrar todas sus tablas y descargarlas perfectamente ordenadas en una sola línea de código.

## Tu ruta de aprendizaje hoy:
1. **Teoría (`teoria.md`)**: El concepto del apodo (`as`) y cómo funciona la aspiradora `read_html`.
2. **Ejemplo (`ejemplo.py`)**: Extraeremos datos de Wikipedia en un abrir y cerrar de ojos.
3. **Reto (`reto.md`)**: Te convertirás en un ladrón de tablas para robar los datos de las películas más taquilleras.

¡Prepárate para dejar las pinzas y encender la aspiradora!
