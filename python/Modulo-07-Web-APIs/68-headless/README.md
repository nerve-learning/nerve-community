# Nivel 68: El Navegador Fantasma (Headless) 👻

En el Nivel 65, viste cómo Selenium abría mágicamente una ventana de Chrome y la controlaba. Es muy divertido ver a tu computadora navegar por sí sola.

Sin embargo, hay un problema en el mundo real:
Si programas un bot para que revise precios todos los días a las 3:00 AM desde un servidor en la nube... ¡ese servidor no tiene pantalla! No puede dibujar ventanas. 

Además, dibujar ventanas gasta muchísima memoria (RAM) y procesador. Si abres 10 navegadores normales a la vez, tu computadora podría congelarse.

Para solucionar esto existe el **Modo Headless** (Sin cabeza). Un navegador "Headless" es un navegador que funciona **exactamente igual**, pero de forma 100% invisible en el fondo. Es un navegador fantasma.

## Tu ruta de aprendizaje hoy:
1. **Teoría (`teoria.md`)**: La Dark Kitchen y cómo ponerle la capa de invisibilidad a Chrome.
2. **Ejemplo (`ejemplo.py`)**: Nuestro primer viaje en las sombras.
3. **Reto (`reto.md`)**: Convertirte en un espía invisible para extraer datos sin ser detectado por los ojos humanos.

¡Prepárate para programar en las sombras!
