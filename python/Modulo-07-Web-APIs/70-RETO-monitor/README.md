# Nivel 70: Proyecto Final - El Guardia de Seguridad (Monitor Web) 🦉

¡Felicidades! Has llegado al proyecto final del Módulo 7. 
Durante este módulo aprendiste a comunicarte con Internet (`requests`), a leer diferentes formatos (`json`, `beautifulsoup`), a controlar navegadores fantasma (`selenium`) y a ser un buen ciudadano digital (`rate limiting`).

En el mundo real, los desarrolladores rara vez corren un script una sola vez de forma manual. Lo normal es crear programas que se ejecutan solos 24/7. Un caso muy común es crear un **Monitor**: un bot que vigila constantemente una página web para avisarte si bajó de precio un vuelo, si salió a la venta un boleto de concierto, o si el servidor de tu empresa se cayó en plena madrugada.

Hoy juntaremos todas las piezas del rompecabezas para construir nuestro propio Monitor Web.

## Tu ruta de aprendizaje hoy:
1. **Teoría (`teoria.md`)**: Las 4 piezas clave para construir un monitor que no destruya Internet.
2. **Ejemplo (`ejemplo.py`)**: Un guardia nocturno básico que vigila un servidor.
3. **Reto (`reto.md`)**: El examen final del módulo. Construirás un "Monitor de Caídas" para vigilar múltiples servidores a la vez en un bucle infinito.

¡Ponte tu uniforme de guardia de seguridad y empecemos a vigilar Internet!
