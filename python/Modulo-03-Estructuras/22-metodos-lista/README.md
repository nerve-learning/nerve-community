# Nivel 22: Modificando la Caja (Métodos de Lista) 🛠️

En el nivel anterior aprendimos a crear una lista (nuestra caja organizadora). Pero una caja donde no puedes meter cosas nuevas ni sacar las que ya no necesitas no es muy útil, ¿verdad?

En la vida real, tu mochila cambia: metes un libro nuevo, sacas una manzana para comerla. En Python, hacemos esto usando **Métodos**.

Los métodos son como pequeños "botones" o "comandos secretos" que tienen las listas para modificarse a sí mismas. Hoy aprenderemos los dos botones más importantes: el botón de "agregar" y el botón de "quitar".

### Ruta de aprendizaje
1. **Teoría**: El punto mágico `.` y cómo dar órdenes a una lista.
2. **Ejemplo**: Gestionando los pasajeros de un autobús.
3. **Reto**: ¡El menú del restaurante!
