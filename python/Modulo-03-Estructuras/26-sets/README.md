# Nivel 26: El Club Exclusivo (Sets / Conjuntos) 🎟️

Imagina que estás organizando una fiesta muy exclusiva. Tienes una lista de invitados, pero algunas personas, de tan emocionadas que estaban, se registraron tres veces. 

Si usamos una **Lista** normal, tendríamos nombres repetidos y compraríamos más comida de la necesaria. Necesitamos una forma de decirle a Python: "Guarda a estas personas, pero **elimina a los repetidos automáticamente**".

Para eso existen los **Sets** (Conjuntos). Un Set es como la entrada a un club VIP: no importa cuántas veces intentes entrar con el mismo nombre, el guardia (Python) solo te contará una vez. Además, en la pista de baile (el Set), nadie tiene un asiento fijo (no hay orden).

### Ruta de aprendizaje
1. **Teoría**: Las llaves `{}` sin parejas y la magia de los elementos únicos.
2. **Ejemplo**: Limpiando una lista de elementos duplicados.
3. **Reto**: ¡La colección de estampas!
