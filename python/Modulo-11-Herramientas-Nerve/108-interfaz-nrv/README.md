# Nivel 108: Los Ojos de Nerve 👁️

¡Hola de nuevo! Hasta ahora hemos aprendido a enviar mensajes y guardar secretos. Pero imagina que tienes 5 programas conectados pasándose datos. ¿Cómo sabes si alguno se apagó por error? ¿Cómo sabes cuántos mensajes se están enviando? 

Trabajar a ciegas es peligroso. Todo buen arquitecto de software necesita un "centro de comando" para supervisar qué está pasando dentro de su red local en tiempo real. 

Afortunadamente, Nerve viene equipado con dos herramientas visuales increíbles que funcionan como "ventanas" hacia tu sistema. Hoy aprenderás a usarlas y te convertirás en el supervisor de tu propia matriz.

### Ruta de Aprendizaje
1. **Teoría**: El monitor de texto, el mapa web y la tecla mágica.
2. **Ejemplo**: Lanzando nuestra primera interfaz gráfica web.
3. **Reto**: Construir un centro de comando interactivo.
