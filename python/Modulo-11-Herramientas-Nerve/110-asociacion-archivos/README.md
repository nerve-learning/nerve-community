# Nivel 110: Instaladores Mágicos (Asociación de Archivos) 🪄

Cuando creas un programa increíble que guarda datos de forma segura usando Nerve, quieres que tus usuarios tengan la mejor experiencia posible. No quieres decirles "abre la terminal y escribe comandos". Quieres que simplemente hagan doble clic y todo funcione.

En este nivel aprenderemos a crear un "Instalador" y "Desinstalador" en Python. Usaremos lo que aprendimos sobre cómo hablarle a la computadora (`os.system`) para que nuestro programa de Python le enseñe a la computadora del usuario qué hacer con los archivos `.nrv`. ¡Este es el toque final para hacer programas profesionales!

## Ruta de Aprendizaje
1. **Teoría**: Cómo Python puede configurar el sistema operativo usando Nerve.
2. **Ejemplo**: Un script instalador que prepara la computadora del usuario.
3. **Reto**: Crear el desinstalador para dejar todo como estaba.
