# Nivel 104: El Puente al Mundo Exterior (`nerve bridge`) 🌉

¡Bienvenido al Nivel 104! Hasta ahora, nuestro sistema nervioso ha estado completamente aislado, corriendo de forma segura dentro de tu propia computadora. Todos los programas hablaban el idioma interno de Nerve (UDS o TCP directo).

Pero, ¿qué pasa si quieres que una página web (ejecutándose en Google Chrome o Firefox) hable con tu red de Nerve? Las páginas web no pueden hablar el idioma interno de Nerve por razones de seguridad de los navegadores.

¡Aquí entra la herramienta **`nerve bridge`**!

## ¿Qué aprenderás aquí?

1. Qué es el comando `nerve bridge`.
2. Cómo funciona un "proxy" o puente para navegadores web (WebSockets).
3. Cómo exponer tu red local de Nerve a herramientas externas de forma segura.

## Archivos en este nivel:

- **`teoria.md`**: Descubrirás el concepto del recepcionista bilingüe (el puente).
- **`ejemplo.py`**: Veremos cómo un cliente normal de Python se entera de lo que pasa en el puente.
- **`reto.md`**: Tu misión será encender el puente y observar cómo se conecta con el Hub.
