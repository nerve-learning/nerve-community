# Nivel 106: Criptografía en NRV 🛡️

¡Hola de nuevo! En el nivel anterior aprendimos a empacar archivos en un cofre seguro llamado `.nrv`. Usamos contraseñas como "agente007" o "alenia_123".

Pero en la vida real, una computadora malvada puede intentar adivinar tu contraseña probando miles de millones de palabras por segundo. Si usas "1234", ¡tu caja fuerte se abrirá en un parpadeo!

Hoy vamos a entender cómo Nerve blinda tus cofres por dentro usando matemáticas avanzadas (criptografía) y aprenderemos a usar Nerve para forjar llaves perfectas que ni las supercomputadoras puedan romper.

### Ruta de Aprendizaje
1. **Teoría**: La licuadora matemática, el candado gigante y el guardián lento.
2. **Ejemplo**: Cómo forjar llaves inquebrantables.
3. **Reto**: Convertirte en un maestro herrero de seguridad.
