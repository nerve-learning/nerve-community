# Nivel 107: Desempaquetado Mágico 🎁

¡Hola de nuevo! Ya eres todo un experto empacando archivos seguros y creando contraseñas impenetrables con Nerve. Pero hay un pequeño problema...

Imagina que le envías un archivo `.nrv` súper seguro a un amigo o a tu jefe. ¡Ellos no van a saber abrir la terminal, escribir `NERVE_NRV_PASSWORD=...` ni comandos complicados! Para que la tecnología sea realmente útil en el mundo real, debe ser fácil de usar para los humanos.

En este nivel aprenderemos cómo hacer que Nerve funcione como un programa "normal": abriendo los archivos mágicamente con **doble clic** o preguntando la contraseña de forma amable en una pequeña ventanita.

### Ruta de Aprendizaje
1. **Teoría**: La asociación de archivos y la apertura interactiva.
2. **Ejemplo**: Enseñándole a tu computadora a reconocer a Nerve.
3. **Reto**: Envolver un regalo y abrirlo con tus propias manos.
