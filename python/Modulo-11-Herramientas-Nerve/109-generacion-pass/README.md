# Nivel 109: El Llavero Automático 🤖

¡Hola de nuevo! En niveles anteriores aprendiste a crear llaves inquebrantables con Nerve y a usarlas para proteger tus cofres `.nrv`. 

Pero había un pequeño detalle humano: tenías que mirar la llave en la pantalla, copiarla y pegarla tú mismo en el código. ¿Qué pasa si estás construyendo un sistema para un banco que necesita empacar y proteger 1000 archivos por segundo? Un humano no puede copiar y pegar tan rápido.

Hoy daremos el salto hacia la **Automatización Pura**. Aprenderás cómo hacer que Python "atrape" la llave generada por Nerve antes de que salga en la pantalla y la use automáticamente para cerrar un cofre. ¡Tu programa se volverá 100% independiente!

### Ruta de Aprendizaje
1. **Teoría**: Escuchando a la terminal con un túnel secreto.
2. **Ejemplo**: Atrapando llaves en el aire.
3. **Reto**: Construir la fábrica de secretos.
