# Nivel 101: El Corazón de la Red 🫀

Hasta ahora hemos usado código en Python para hablar, pero nos falta entender a la pieza más importante del rompecabezas: el **Enrutador** (o Hub).

Imagina que quieres enviarle una carta a tu vecino. Podrías ir caminando y dejarla en su buzón. Pero si quieres enviarle cartas a 10 vecinos al mismo tiempo en milisegundos, necesitas una Oficina de Correos. 

En la vida real de Nerve, esa Oficina de Correos no es código Python que tú escribes, es un programa que ya viene instalado y se ejecuta desde tu terminal (tu consola de comandos). Se llama **NexusHub** y se enciende con un simple comando: `nerve start`.

En este nivel aprenderemos a encender nuestra Oficina de Correos y a ver en tiempo real cómo clasifica los mensajes usando el modo espía (verbose).

## Ruta de Aprendizaje

1. **Teoría (`teoria.md`)**: Entenderemos qué es la CLI (Interfaz de Línea de Comandos) de Nerve y el modo Verbose.
2. **Ejemplo (`ejemplo.py`)**: Ejecutaremos nuestro propio programa mensajero para ver cómo el Hub procesa la información.
3. **Reto (`reto.md`)**: Encenderás el Hub, lo pondrás en modo espía, y verás las tripas de la comunicación.
