# Nivel 105: Empaquetado Básico 📦

¡Hola de nuevo, futuro arquitecto! Hasta ahora has aprendido a conectar aplicaciones para que hablen entre sí en tiempo real usando Nerve. Pero, ¿qué pasa cuando necesitas enviar *archivos* enteros de forma segura, o guardar datos sensibles para que nadie más los lea?

En la vida real, si tienes documentos secretos, no los llevas en la mano por la calle; los metes en una caja fuerte y la cierras con llave. En el mundo de Nerve, esa caja fuerte se llama un archivo **.nrv**.

Hoy aprenderás a usar el motor criptográfico de Nerve para empaquetar y proteger cualquier archivo o carpeta. 

### Ruta de Aprendizaje
1. **Teoría**: Entenderemos cómo funciona la "caja fuerte" `.nrv` y la llave temporal.
2. **Ejemplo**: Crearemos una bóveda desde código y la abriremos mágicamente.
3. **Reto**: Convertirte en un mensajero cifrado.

¡Da tu primer paso seguro hacia adelante!
