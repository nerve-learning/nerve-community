# Nivel 44: Cajas Mágicas y Etiquetas (`*args` y `**kwargs`) 🪄

En el nivel anterior aprendimos a dejar valores "por defecto" (un Plan B). Y prometimos que aprenderíamos a romper el estricto orden de izquierda a derecha. Hoy cumplimos esa promesa.

Además, nos enfrentaremos a un nuevo problema: ¿Qué pasa si estás construyendo un carrito de compras y no sabes cuántos productos va a meter el usuario? ¿Deberías crear una función con 100 parámetros por si acaso? ¡No!

En la vida real, si vas a una tienda, no llevas una bolsa especial para cada uva que compras. Llevas **una sola bolsa grande** y metes todas las uvas ahí.

En Python, existen dos símbolos mágicos que actúan como "bolsas infinitas":
1. El asterisco simple `*`: Crea una bolsa para cosas sueltas.
2. El asterisco doble `**`: Crea un archivero para cosas con etiqueta.

## 🗺️ Ruta de Aprendizaje
1. **Teoría:** Aprenderemos a llamar a los ingredientes por su nombre (Keyword Arguments) y a usar los símbolos `*` y `**` para atrapar cantidades infinitas de datos.
2. **Ejemplo:** Crearemos un sistema que recibe cualquier cantidad de invitados y configuraciones.
3. **Reto:** Programarás el "Inventario Infinito" de un aventurero.

¡Prepárate para darle superpoderes de flexibilidad a tus funciones!
