# Nivel 2: El Grifo vs El Cubo 🚿🪣

## ¿Por qué aprender esto?

Ahora que sabes usar `yield` para crear funciones que pausan, vamos a entender **qué es exactamente** lo que se crea cuando llamas a esa función. Se llama **generador**, y tiene un superpoder que las listas no tienen: usa casi cero memoria, sin importar cuántos valores pueda producir.

Si en el nivel anterior construiste el chef, ahora aprenderás a entender su naturaleza: por qué consume tan poca energía y cuándo conviene usarlo en vez de una lista.

## Ruta de Aprendizaje

1. 📖 Lee `teoria.md` — entiende la diferencia entre guardar todo y producir bajo demanda
2. 🐍 Estudia `ejemplo.py` — ve la diferencia de comportamiento en la terminal
3. 🔥 Completa `reto.md` — construye un generador que filtra datos de un "archivo" enorme

## Conceptos que usarás aquí

`def`, `yield`, `for`, `if`, listas `[]`, f-strings, `print()`, lo aprendido en el nivel anterior
