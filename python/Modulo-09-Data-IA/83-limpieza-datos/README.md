# Nivel 83: Limpieza de Datos - El Arte de Ordenar el Caos 🧹

En el nivel anterior creamos tablas perfectas, pero te diré un secreto: **en el mundo real, los datos son un completo desastre.**

Los usuarios se olvidan de rellenar campos, los sensores fallan y de repente tienes una tabla llena de "huecos" donde debería haber información. En la ciencia de datos hay una regla de oro: *Garbage In, Garbage Out* (Si metes basura, sale basura). Si intentas sacar promedios o usar Inteligencia Artificial con datos que tienen huecos, tus programas van a explotar.

El 80% del trabajo de un científico de datos no es crear IAs súper complejas, sino barrer y limpiar los datos para que sean usables. ¡Hoy aprenderás a usar la escoba mágica de Pandas!

## Ruta de Aprendizaje
1. **Teoría**: Aprenderemos qué es un `NaN` (el enemigo silencioso) y dos formas de derrotarlo.
2. **Ejemplo**: Veremos cómo borrar a los defectuosos o cómo darles una segunda oportunidad rellenando sus huecos.
3. **Reto**: Rescatarás el inventario de una tienda rellenando los precios perdidos.
