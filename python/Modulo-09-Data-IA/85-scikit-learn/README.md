# Nivel 85: Scikit-Learn - Tu Primera Inteligencia Artificial 🧠

Desde el nivel 1, siempre le hemos dado órdenes exactas a la computadora: "Suma esto", "Borra aquello", "Dibuja esta línea". La computadora solo obedecía ciegamente.

Pero, ¿qué pasaría si, en lugar de darle instrucciones exactas, le damos **ejemplos** y dejamos que ella misma descubra las reglas? Eso es la Inteligencia Artificial (específicamente, el *Machine Learning* o Aprendizaje Automático).

**Scikit-Learn** es la herramienta más famosa de Python para hacer esto. Es como una escuela para computadoras. Tú le entregas datos del pasado (por ejemplo, el clima de los últimos años), la computadora los estudia para encontrar patrones ocultos, y luego usa ese conocimiento para adivinar el futuro.

## Ruta de Aprendizaje
1. **Teoría**: Aprenderemos a crear un "cerebro" virtual, enseñarle a estudiar con `fit`, y hacerle exámenes con `predict`.
2. **Ejemplo**: Entrenaremos a una IA para que adivine el precio de una casa basándose en el número de habitaciones.
3. **Reto**: Crearás un oráculo que prediga cuántos helados venderás según el clima de mañana.
