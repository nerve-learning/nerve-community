# Nivel 81: Numpy - Súper Listas Matemáticas 🧮

Imagina que tienes una caja con 10,000 precios y a todos necesitas sumarles $5 dólares. Si usas una lista normal de Python, tendrías que sacar cada precio uno por uno (usando un bucle `for`), sumarle los $5 y volver a guardarlo. Eso es lento y aburrido.

Aquí es donde entra **Numpy**. 

Numpy nos da unas "súper listas" llamadas **arrays** (arreglos). Estas súper listas son increíbles porque saben hacer matemáticas de golpe. Si le dices a un array "súmate 5", automáticamente le suma 5 a *todos* sus elementos al mismo tiempo, sin necesidad de bucles.

Por esto, Numpy es el motor principal que usan los científicos de datos y las Inteligencias Artificiales: es extremadamente rápido calculando números.

## Ruta de Aprendizaje
1. **Teoría**: Aprenderemos a invocar a Numpy y crear nuestro primer array.
2. **Ejemplo**: Veremos la diferencia entre intentar sumar cosas a una lista normal vs a un array de Numpy.
3. **Reto**: Aplicarás un descuento a varios productos en una sola línea de código.
