# Nivel 89: LLMs (Modelos de Lenguaje Grande) 🦜

¿Alguna vez has usado el teclado de tu celular y te ha sugerido la siguiente palabra que vas a escribir? Bueno, un LLM (Large Language Model) es exactamente eso, pero a una escala monstruosa. Ha leído casi todo el internet y es tan bueno adivinando la siguiente palabra que parece que estuviera razonando o pensando.

En la vida real, saber cómo comunicarte con estos "cerebros digitales" (como ChatGPT o Gemini) te permite automatizar respuestas, analizar textos largos en segundos o crear asistentes virtuales.

## Ruta de aprendizaje
1. **Teoría (`teoria.md`)**: Entenderemos qué es un Prompt, un Modelo y un Completion.
2. **Ejemplo (`ejemplo.py`)**: Construiremos una simulación de cómo se conecta tu código con un LLM.
3. **Reto (`reto.md`)**: Crearás tu propio sistema de respuestas automatizadas.
