# Nivel 51: Rutas y el Mapa del Tesoro 🗺️

¡Hola, explorador! Hasta ahora hemos escrito programas que viven en su propio mundo de variables, listas y funciones. Pero en el mundo real, los programas necesitan interactuar con tu computadora. Necesitan abrir archivos de Excel, guardar imágenes o buscar documentos.

Para hacer eso, primero tienen que saber **dónde están parados**. 

En este nivel aprenderemos cómo hacer que Python "mire a su alrededor" usando **rutas** (las direcciones exactas de las carpetas en tu computadora).

### Tu ruta de aprendizaje hoy:
1. **Teoría**: Entenderemos qué es `os` y cómo Python navega por tu computadora.
2. **Ejemplo**: Haremos que Python nos diga exactamente en qué carpeta está y qué archivos hay a su lado.
3. **Reto**: Construirás un "Inspector de carpetas" para clasificar lo que Python encuentre.

¡Ponte el sombrero de explorador, que empezamos!
