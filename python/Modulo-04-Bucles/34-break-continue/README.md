# Nivel 34: El Freno de Emergencia (Break) 🛑

Imagina que estás buscando tus llaves perdidas en tu casa. Revisas el sillón, la mesa, la cocina... ¡y las encuentras en el refrigerador! Una vez que las encuentras, ¿sigues buscando en el baño y en el cuarto? ¡Claro que no! Detienes la búsqueda de inmediato.

En programación pasa lo mismo. A veces le decimos a la computadora que recorra una lista enorme de datos buscando algo. Cuando lo encuentra, no queremos que pierda tiempo revisando el resto. Para detener el bucle al instante, usamos el freno de emergencia: `break`.

### Ruta de Aprendizaje
1. **Teoría**: Aprenderemos cómo y dónde colocar este botón de parada de emergencia.
2. **Ejemplo**: Acompañaremos a un detective a buscar un objeto perdido en un cajón.
3. **Reto**: Construirás un sistema de seguridad para detectar intrusos y detener un proceso.
