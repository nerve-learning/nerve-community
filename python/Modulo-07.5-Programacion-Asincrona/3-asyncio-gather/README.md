# Nivel 03: Magia Simultánea (asyncio.gather) ⚡

En el nivel anterior aprendimos a pausar funciones, pero las ejecutamos una por una (primero el agua, luego el café). ¡Eso no nos ahorró tiempo!

1. **Teoría:** La función `asyncio.gather()`.
2. **Ejemplo:** Cocinando en paralelo.
3. **Reto:** La carrera de caballos.
