# Nivel 05: Cuando el Internet Falla (Manejo de Errores) 🛡️

Internet es inestable. Una URL puede dejar de existir, el servidor puede caerse, o te puedes quedar sin WiFi. En el módulo de calidad de código aprendimos a usar `try` y `except` para atrapar errores y evitar que el programa explote.

Hoy aprenderemos cómo aplicarlo de forma segura en nuestro Bucle de Eventos para que una petición fallida no mate al resto de peticiones que están funcionando.

## 🗺️ Ruta de aprendizaje
1. **Teoría:** Integrando `try/except` con `await` y `gather`.
2. **Ejemplo:** Sobreviviendo a un link roto.
3. **Reto:** El recolector blindado.
