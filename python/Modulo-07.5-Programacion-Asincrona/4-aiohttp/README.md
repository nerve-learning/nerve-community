# Nivel 04: Peticiones Web Asíncronas (aiohttp) 🌐

En el módulo pasado (Web APIs) aprendimos a comunicarnos con internet usando la librería `requests`. Sin embargo, `requests` es síncrono: bloquea el programa entero mientras espera que la página web responda.

Hoy instalaremos e introduciremos `aiohttp`, el hermano asíncrono de `requests`.

## 🗺️ Ruta de aprendizaje
1. **Teoría:** Instalación y el concepto de Sesión y Gestor de Contexto asíncrono.
2. **Ejemplo:** Pidiendo datos a una API sin bloquear.
3. **Reto:** Tu primera petición asíncrona.
