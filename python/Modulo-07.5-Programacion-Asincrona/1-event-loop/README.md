# Nivel 01: El Bucle de Eventos (Event Loop) 🎡

¿Alguna vez has esperado 10 minutos a que hierva el agua, mirando la olla sin hacer nada más? En la vida real, mientras el agua hierve, aprovechas para picar la verdura. 

En la programación, normalmente el código espera (se bloquea) hasta que una tarea termina. Hoy aprenderemos a darle a Python un "Director de Orquesta" llamado **Bucle de Eventos** (Event Loop), que le permite aprovechar los tiempos muertos.

## 🗺️ Ruta de aprendizaje
1. **Teoría:** ¿Qué es la programación asíncrona y el Event Loop?
2. **Ejemplo:** Nuestro primer encuentro con el jefe.
3. **Reto:** Invocar al Event Loop por ti mismo.
