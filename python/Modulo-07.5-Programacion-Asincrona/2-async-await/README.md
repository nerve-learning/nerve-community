# Nivel 02: Pausar y Retomar (Async / Await) ⏸️

Ahora que tenemos al Jefe de Cocina (el Event Loop), necesitamos darle recetas especiales. En el mundo asíncrono, las funciones normales no sirven, necesitamos funciones que sepan "pausarse" para dejar que otras cosas ocurran.

## 🗺️ Ruta de aprendizaje
1. **Teoría:** Los poderes de `async` y `await`.
2. **Ejemplo:** Esperando de forma inteligente.
3. **Reto:** Un desayuno asíncrono.
