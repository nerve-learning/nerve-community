# Nivel 06: Proyecto Final - Scraper Concurrente 🏆

¡Has llegado al jefe final de la Programación Asíncrona! 
Hasta ahora has estado practicando con 1 o 2 páginas a la vez. En el mundo real, los ingenieros de datos y desarrolladores web necesitan descargar docenas, cientos o miles de páginas web lo más rápido posible.

En este reto final, vas a unir todos los conceptos que has aprendido (Event Loop, async/await, gather, aiohttp y manejo de errores) para extraer información de un sitio web especial diseñado por Alenia Studios para aprender Web Scraping.

## 🗺️ Ruta de aprendizaje
1. **Teoría:** Repaso mental de tu arsenal asíncrono.
2. **Ejemplo:** La estructura de un scraper real.
3. **Reto:** Extraer la información de `nerve.community.aleniastudios.me`.
