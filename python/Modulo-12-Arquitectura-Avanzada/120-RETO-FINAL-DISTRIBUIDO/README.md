# Nivel 120: El Reto Final - Sistemas Distribuidos 🌐

¡Felicidades por llegar a la cima! Has pasado de no saber cómo imprimir un texto en pantalla, a construir piezas de software que se comunican entre sí en tiempo real.

En el mundo real de la ingeniería de software, aplicaciones gigantescas como Netflix, Uber o WhatsApp no son un solo programa masivo. Si lo fueran, cuando fallara una pequeña parte (como el sistema de cobro), se caería todo el servicio. 

Para evitar esto, usamos una **Arquitectura de Microservicios** (Sistemas Distribuidos). Dividimos el problema gigante en pequeños "mini-programas" que corren por separado y se comunican a través de un "cerebro" central.

### ¿Por qué esto es un superpoder?
- **Resiliencia**: Si el bot que envía correos se apaga, el bot que cobra sigue funcionando.
- **Especialización**: Cada bot hace **una sola cosa** y la hace perfecto.
- **Escalabilidad**: Si hay mucho tráfico, puedes prender 5 copias del mismo bot para ayudar, sin tocar el resto del sistema.

### Tu Ruta de Aprendizaje
1. **Teoría**: Entenderás cómo instalar y orquestar múltiples piezas en la vida real.
2. **Ejemplo**: Veremos un script "metamorfo" que puede ser Sensor o Pantalla.
3. **Reto**: Construirás tu propio ecosistema de tres piezas desde cero.
