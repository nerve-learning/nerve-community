# Nivel 11: Operadores Lógicos ⚖️

En la vida real, casi nunca tomamos decisiones con una sola regla. Por ejemplo, para que te dejen salir a una fiesta no solo necesitas "haber terminado la tarea", también necesitas "limpiar tu cuarto". Son dos condiciones que deben ser verdad al mismo tiempo.

Para que nuestros programas dejen de ser básicos y puedan evaluar escenarios de la vida real, usamos los **Operadores Lógicos**. Son el equivalente a las palabras "y", "o", y "no" que usamos todos los días.

## Ruta de aprendizaje
1. **teoria.md**: Aprenderás cómo combinar verdades (`True`) y mentiras (`False`) usando `and`, `or` y `not`.
2. **ejemplo.py**: Programaremos a los estrictos guardianes de una sala de cine.
3. **reto.md**: Construirás el sistema de acceso inteligente para una montaña rusa.
