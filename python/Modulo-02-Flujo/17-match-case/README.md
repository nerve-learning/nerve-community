# Nivel 17: El Clasificador Automático (`match-case`) 🗂️

En niveles anteriores vimos que podíamos usar muchísimos `elif` si teníamos muchas opciones (como un menú de restaurante con 10 platillos). Aunque funciona, escribir `if platillo == "A":`, `elif platillo == "B":` una y otra vez se vuelve aburrido y difícil de leer.

Imagina que eres un cartero en una oficina postal. No vas leyendo cada carta diciendo "Si es para la calle 1, la pongo aquí, si no, si es para la calle 2...". Simplemente tomas la carta, miras la calle y la lanzas directamente a su casillero. ¡Eso es exactamente lo que hace `match-case`!

## Ruta de aprendizaje
1. **teoria.md**: Conocerás las palabras mágicas `match` (el objeto a revisar) y `case` (los casilleros), además del comodín `_`.
2. **ejemplo.py**: Crearemos un conmutador telefónico y un menú de cafetería.
3. **reto.md**: Programarás el menú del servicio de atención al cliente de un banco.
