# Nivel 12: Comparadores (Detectives de Datos) 🕵️‍♂️

En el mundo real, pasamos el día entero comparando cosas: "¿Tengo suficiente dinero para esto?", "¿Esta talla es más grande que la mía?", "¿Mi contraseña es exactamente igual a la que registré?".

Para que nuestros programas puedan tomar decisiones inteligentes, primero deben aprender a **comparar**. Los comparadores son como pequeños detectives que observan dos datos y siempre nos responden con la verdad (`True`) o una mentira (`False`). 

## Ruta de aprendizaje
1. **teoria.md**: Aprenderás la diferencia crucial entre `=` (guardar) y `==` (comparar), y conocerás a los 6 detectives de Python.
2. **ejemplo.py**: Usaremos a nuestros detectives para vigilar el acceso a un club secreto.
3. **reto.md**: Crearás un sistema de escaneo de equipaje para un aeropuerto.
