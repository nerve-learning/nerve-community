# Nivel 100: Topología de Red y Monitoreo 🌐

¡Felicidades! Has llegado al nivel 100. En este punto ya sabes cómo conectar nodos locales para que se envíen mensajes usando **Nerve**. Pero, ¿qué forma tiene nuestra red cuando conectamos 5, 10 o 50 programas diferentes?

En este nivel aprenderemos sobre la **Topología Estrella** que usa Nerve y cómo usar las herramientas que vienen incluidas (`nerve dashboard`) para visualizar en tiempo real todos los nodos que están hablando en nuestra computadora.

## Ruta de Aprendizaje

1. **Teoría (`teoria.md`)**: Entenderemos qué es una topología estrella y el rol del Hub.
2. **Ejemplo (`ejemplo.py`)**: Levantaremos varios clientes en un solo programa para ver cómo se conectan.
3. **Reto (`reto.md`)**: Tu misión será lanzar la red y visualizarla usando el dashboard oficial.
