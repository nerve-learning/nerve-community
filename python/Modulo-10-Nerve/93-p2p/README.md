# Nivel 93: Comunicación P2P (Peer-to-Peer) 🏓

En los niveles pasados, construimos dos cosas separadas:
1. Un programa que solo hablaba (el mensajero del Nivel 91).
2. Un programa que solo escuchaba (la alarma del Nivel 92).

Pero la verdadera magia de los sistemas distribuidos ocurre cuando los programas pueden tener **conversaciones completas**, donde ambos hablan y escuchan al mismo tiempo, como si estuvieran jugando un partido de ping-pong. 

A esta arquitectura, donde dos nodos son iguales y se comunican directamente el uno con el otro, se le llama **Peer-to-Peer** (abreviado **P2P**, que significa "Punto a Punto" o "Colega a Colega"). Es la base de las aplicaciones de chat, juegos multijugador y sistemas de sincronización.

## Ruta de Aprendizaje

1. **Teoría (`teoria.md`)**: Entenderemos cómo combinar el "recepcionista" y el "megáfono" sin que nuestro código explote.
2. **Ejemplo (`ejemplo.py`)**: Construiremos nuestro propio chat en vivo P2P de consola.
3. **Reto (`reto.md`)**: Desarrollarás dos radios Walkie-Talkie para simular una misión de rescate.
