# Nivel 03: Letras y Números (Textos y Enteros) 🔤🔢

Hasta ahora hemos guardado mensajes en nuestras cajas mágicas, siempre usando comillas. Pero, ¿qué pasa si queremos guardar nuestra edad o la puntuación de un juego? 

En la vida real, sabes que la palabra "cinco" y el número `5` representan lo mismo en tu cabeza, pero para la computadora son dos universos totalmente diferentes. La computadora necesita saber si el `5` que le das es solo un "dibujo" (texto) o una cantidad real (matemática). 

**Ruta de aprendizaje:**
1. **Teoría:** Aprenderemos la diferencia vital entre un texto (String) y un número entero (Integer).
2. **Ejemplo:** Veremos cómo se escriben en código.
3. **Reto:** Registrarás los datos de un viajero espacial.
