# Nivel 08: Notas para Humanos (Comentarios) 📝

A medida que tus programas crecen, se vuelven más complejos. Escribir código no se trata solo de darle instrucciones a la máquina, sino de comunicarte con otros humanos (¡incluyendo a tu "yo" del futuro!) para explicar *por qué* hiciste algo.

Aquí es donde entran los **Comentarios**. Son líneas de texto que tú puedes leer, pero que la computadora ignora por completo. Es tu espacio seguro para dejar notas.

**Ruta de aprendizaje:**
1. **Teoría:** Aprenderemos el símbolo de invisibilidad.
2. **Ejemplo:** Veremos cómo documentar nuestro trabajo.
3. **Reto:** Explicarás tu propio código.
