# Nivel 71: Clases y Objetos 🏭

¡Bienvenido al Módulo 8! Hasta ahora, hemos usado tipos de datos que ya vienen construidos en Python (como las listas `[]` o los diccionarios `{}`). También hemos agrupado nuestra lógica usando funciones (`def`).

Pero en la vida real, las cosas son más complejas. Si quisieras crear un programa para gestionar los empleados de una empresa, un diccionario se quedaría corto muy rápido. Necesitas algo que agrupe **los datos del empleado** (su nombre, su edad) y **las acciones del empleado** (cobrar sueldo, tomar vacaciones) en un solo paquete.

Aquí es donde entran las **Clases** y los **Objetos**, la base de la Programación Orientada a Objetos (POO). Este nivel marca un antes y un después en tu camino como programador. ¡Estás a punto de aprender a crear tus propios tipos de datos!

## Ruta de aprendizaje
1. **Teoría (`teoria.md`)**: Entenderemos qué es un "molde" y qué es un "objeto", desgranando cada símbolo nuevo.
2. **Ejemplo (`ejemplo.py`)**: Veremos cómo crear nuestra primera fábrica de robots.
3. **Reto (`reto.md`)**: Te tocará crear una fábrica de monstruos. ¡A programar!
