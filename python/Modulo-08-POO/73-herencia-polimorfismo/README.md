# Nivel 73: Herencia y Polimorfismo 🧬

A medida que tu programa crece, te darás cuenta de que estás repitiendo mucho código. Si estás creando un videojuego con Leones, Tigres y Osos, todos ellos necesitan una función `comer()`, `dormir()`, y `respirar()`. 

¿Vas a escribir la misma función tres veces? ¡Claro que no! Los programadores odian repetir código (es la regla de oro llamada DRY: *Don't Repeat Yourself*). 

Para solucionar esto, usamos la **Herencia**: creamos una clase "Padre" (ej. `Animal`) que tenga las cosas comunes, y hacemos que las clases "Hijas" hereden ese código gratis. 

El **Polimorfismo**, por otro lado, es una palabra muy elegante para un concepto muy simple: que varios objetos compartan la misma acción (ej. `hacer_sonido()`), pero que cada uno la ejecute a su manera (el león ruge, el perro ladra).

## Ruta de aprendizaje
1. **Teoría (`teoria.md`)**: Entenderemos cómo se conectan los padres e hijos en el código, y cómo "aplastar" funciones.
2. **Ejemplo (`ejemplo.py`)**: Construiremos nuestro primer zoológico digital.
3. **Reto (`reto.md`)**: Trabajarás en un taller de vehículos creando coches y bicicletas. ¡A programar!
